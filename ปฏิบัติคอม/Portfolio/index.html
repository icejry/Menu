วิศวกรรมคอมพิวเตอร์

เกี่ยวกับตัวฉัน

มีความสนใจในด้านเทคโนโลยีคอมพิวเตอร์และการพัฒนาเว็บไซต์ สามารถศึกษาค้นคว้าความรู้ใหม่ๆ ได้ด้วยตนเอง มีความมุ่งมั่น และรับผิดชอบในการทำงาน ชอบพัฒนาทักษะด้านการเขียนโปรแกรม และตั้งเป้าหมายที่จะนำความรู้ทางวิศวกรรมคอมพิวเตอร์ ไปประยุกต์ใช้ในการเรียนและการทำงานในอนาคต

ประวัติการศึกษา

  1. พ.ศ.2565 จบระดับมัธยมศึกษาตอนต้น — โรงเรียนรัตนราษฎร์บำรุง จ.ราชบุรี
  2. พ.ศ.2568 จบระดับมัธยมศึกษาตอนปลาย — โรงเรียนสารสิทธิ์พิทยาลัย จ.ราชบุรี
  3. พ.ศ.2572 จบระดับอุดมศึกษา — มหาวิทยาลัยเทคโนโลยีราชมงคลพระนคร

ความเชี่ยวชาญ

  • สามารถใช้งานโปรแกรมคอมพิวเตอร์พื้นฐานและโปรแกรมสำนักงานได้
  • มีพื้นฐานด้านการออกแบบและพัฒนาเว็บไซต์
  • เขียนเว็บไซต์ด้วย HTML และ CSS ได้
  • มีพื้นฐานการเขียนโปรแกรมและการคิดเชิงตรรกะ
  • สามารถเรียนรู้และประยุกต์ใช้เทคโนโลยีใหม่ได้

ทักษะและความสามารถ

  • เรียนรู้สิ่งใหม่และพัฒนาตนเองอยู่เสมอ
  • มีความคิดริเริ่มและสามารถแก้ไขปัญหาได้
  • มีความรับผิดชอบและตรงต่อเวลา
  • สามารถทำงานร่วมกับผู้อื่นและทำงานเป็นทีมได้
  • มีความมุ่งมั่นและตั้งใจในการทำงาน

ประสบการณ์และผลงาน

  1. พัฒนาเว็บไซต์สำหรับสาขาวิศวกรรมคอมพิวเตอร์
  2. พัฒนาเว็บไซต์ส่วนตัวเพื่อนำเสนอข้อมูลของตนเอง
132-1 นายจิรายุ ชิยานุวัฒน์ สาขาวิศวกรรมคอมพิวเตอร์ คณะวิศวกรรมศาสตร์ มหาวิทยาลัยเทคโนโลยีราชมงคลพระนคร
